Que dato de Redukt vive en cada nivel

L1d (48 KB)
Vector token (768B) | Acumuladores i32 (3KB) | RWKV state (24KB/layer) | Mixer+Coder (5KB)
L2 (1.25 MB)
TimeMix weights Q8 (576KB) | ChannelMix weights Q8 (576KB) | LoRA F32 (~96KB) | Ngram hash (~512KB)
Layer weights caben en L2 con presion — el working set rota por capa
L3 (12 MB)
1-2 capas de pesos simultaneas (~4MB) | NO cabe el modelo completo (130MB)
DRAM (32 GB)
Head weights Q8 (48MB) | Embedding table (48MB) | Modelo total Q8 (~130MB)
